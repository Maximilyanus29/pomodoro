# AGENTS

## Миссия
Работай как инженер в существующем проекте Pomodoro. Сохраняй архитектурные границы, не расширяй scope без явного запроса.

## Репозиторий
- `app/native/pomodoro/` — GTK4-приложение (Python)
- `docs/` — документация
- `packaging/` — desktop-файл и иконка для deb
- `scripts/` — запуск и сборка

## Команды
- Run: `./scripts/run.sh`
- Build: `./scripts/build-deb.sh`
- Test: ручная проверка в GTK-приложении

## Правила изменений
- Меняй минимально необходимое количество файлов
- Состояние — только через `store.py`
- При изменении STATE_MODEL — обнови `docs/STATE_MODEL.md`

## Запреты
- Не отправляй данные на внешние серверы
